## Formulation difficulty

Difficulty ratings assess GD problem formulation in this study using five dimensions:

- **D1:** Load derivation.
- **D2:** Load-case count.
- **D3:** Interfaces and supports.
- **D4:** Spatial and manufacturing constraints.
- **D5:** Special requirements and functional decomposition.

Each dimension is scored from 0 to 2. The five scores are summed to assign a difficulty level:

| Level | Total score | Cases |
|---|---:|---|
| L1 | 0–3 | C1–C3 |
| L2 | 4–6 | C4–C7 |
| L3 | 7–10 | C8–C10 |
